# Adidas Product Performance & Pricing Analysis Dashboard

## 📊 Project Overview
This project focuses on analyzing product performance and pricing strategies for Adidas products in the Indian market using Power BI. The dashboard provides interactive insights into pricing, discounts, ratings, and availability to support data-driven decision-making.

---

## 🎯 Objectives
- Analyze product distribution across categories and price segments
- Understand the impact of discounts on product ratings
- Identify top-performing products and categories
- Monitor product availability and inventory trends

---

## 📂 Dataset
- Source: Kaggle
- Contains product details such as:
  - Product Name
  - Category
  - Gender
  - Price
  - Discount
  - Rating
  - Availability

---

## ⚙️ Tools & Technologies
- Microsoft Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)

---

## 🔄 Workflow
1. Data collection from Kaggle  
2. Data cleaning using Power Query (Table View)  
3. Feature engineering (price segments, discount %)  
4. Data modeling and DAX measures  
5. Dashboard creation with interactive visuals  
6. Deployment using Power BI Service  

---

## 📈 Key Features
- KPI Cards (Total Products, Avg Price, Discount, Rating)
- Product distribution by price segment
- Availability analysis
- Top product categories
- Discount vs Rating analysis
- Interactive filters (Category, Gender, Price Segment)

---

## 🚀 Deployment
The dashboard is published using Power BI Service and can be shared with users for real-time insights.
